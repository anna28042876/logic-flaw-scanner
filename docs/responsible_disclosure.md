# Responsible Disclosure Statement

This project is a research tool developed solely for security research
and education.

- All vulnerability testing is conducted exclusively against locally hosted,
  intentionally vulnerable applications (OWASP Juice Shop, DVWA).
- No findings from this tool will be published, or disclosed without the
  explicit consent of the affected system owner.
- The tool is not distributed publicly and will not be released in a form
  that enables trivial repurposing against live systems.
- Conducted under EthOS ethics approval.
