# Responsible Disclosure Statement

This project is a research tool developed solely for security research
and education.

- All vulnerability testing is conducted exclusively against locally hosted,
  intentionally vulnerable applications (OWASP Juice Shop, DVWA).
- Findings published in this repository relate only to these locally hosted,
  intentionally vulnerable applications.
- Findings against any other system must not be published, or disclosed
  without the explicit consent of the affected system owner.
- The source code is published openly for transparency, education, and
  reproducibility. It must only be used against systems the user owns, or
  has explicit written permission to test.
- The scope enforcer (`scope.py`) restricts requests to the configured target,
  but it is a safeguard, not a substitute for authorisation.
- Conducted under EthOS ethics approval.
